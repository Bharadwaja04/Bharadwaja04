## 👋 About

I'm a **builder**. I like taking an idea from a rough sketch to something people can actually use: developer tools, mobile apps, full-stack products and a few experiments along the way. Most of what's below was built end to end, from the first commit to a working demo.

## 🔨 What I'm building right now

> **🧭 CodeMind** · *developer tool, in active development*
> A quiet map that sits next to your editor and shows how the code you're looking at fits into the rest of the project, in plain words, while an AI agent changes it. So you keep your grip on code you didn't write by hand. (Private repo for now, demo on request.)

> **📱 Incident Assistant** · *on-device mobile app*
> An incident-reporting assistant that runs 100% offline on an Android phone. You speak, it listens, asks follow-ups and files a structured report. No cloud, no internet.

> **🛒 ClaimCheck** · *team project, due mid-November*
> A shopping recommender that enforces your hard constraints in plain code and only states facts the customer reviews support. Built with a team, tested across 21 pipeline configurations.
